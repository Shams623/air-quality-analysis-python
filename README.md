# Air Quality and Pollution Dashboard

## Project Description
This project is an interactive dashboard built using Plotly Dash to analyze air pollution data.

## Features
- Bar Chart
- Scatter Plot
- Histogram
- Box Plot
- Violin Plot
- Line Chart
- Area Chart
- Stacked and Clustered Charts

## Interactive Controls
- Country Dropdown
- Metric Selection
- Top Cities Slider

## How to Run
1. Run:
   py app.py
2. Select dataset
3. Open:
   http://127.0.0.1:8050/
